双色球可预测性研究

用 2003 年以来的全部开奖记录检验两件事：号码能不能预测，开奖是否回避热门号码。每期开奖前，预测会公开存档到 GitHub，事后无法修改。

目前的结论

历史回测

每期都只用此前的数据预测，再与"每个号码等概率"的随机基线做配对检验。2003–2018 年用于挑选正式模型，2019 年以后作为留出测试，只看一次。p < 0.05 并且同时跑赢基线，才算有效。

对数损失增益：正值表示比随机猜得更准。正向命中：概率最高的 6 个红球平均命中几个。反向命中：概率最低的 10 个红球平均误开几个，越少越好。蓝球命中：概率最高的 1 个蓝球的命中率。

前瞻记录

开奖前生成、开奖后核对的预测。每条记录都能在 GitHub 上查到提交时间和 SHA-256 校验值，这一部分是检验可预测性最可靠的证据。

方法与局限

数据来自 500 彩票网历史开奖表，共 期，包括开奖号码、销售额，以及一、二等奖的注数。模型包括热号频率、冷号遗漏、逻辑回归和梯度提升树，特征有多窗口出现频率、遗漏期数、上期是否开出和号码本身。

一等奖空奖期数偏多，是因为彩民集中购买相同号码（同号投注、倍投），中奖注数比泊松分布更分散。空奖多不能单独当作操控的证据，长期总注数才能。

本研究无法检验"开奖视频与公布结果不一致"这类说法，因为没有逐期的原始视频数据。如果有具体的期号，可以把那几期单独拿出来分析。

本站只用于学术研讨，不构成购彩建议。双色球的返奖率约为 50%，长期购买的期望收益为负。
